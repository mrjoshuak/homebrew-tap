# Avalanche-io Homebrew Tap

Homebrew formulae for the [C4 toolkit](https://cccc.io).

## Install

```bash
brew install Avalanche-io/tap/c4
```

This installs:
- **c4** — Content identification CLI
- **c4sh** — Shell integration for browsing c4m files as directories
- **c4git** — Git clean/smudge filter for large binary assets

## Update

```bash
brew update
brew upgrade c4
```
